CHALLENGE #1

그리드, 프레임, 글씨효과 사용한 작품만들기

학습 목표

캔바(Canva)의 핵심 레이아웃 도구인 '그리드(Grids)'와 '프레임(Frames)'을 활용하여 깔끔한 사진 배치를 완성하고, 네온/곡선/스플라이스/그림자 등 다양한 글씨 효과(Text Effects)를 적용해 감각적인 모던 갤러리 포스터를 만듭니다.

STEP 1

캔바 캔버스 생성 및 그리드 레이아웃 배치

  1. 캔바 홈 화면 우측 상단 [디자인 만들기] 버튼 클릭 후 세로형 포스터 (1080 x 1920 px) 또는 인스타그램 게시물 (1080 x 1080 px)을 선택합니다.
  2. 좌측 메뉴 바에서 [요소 (Elements)] 탭을 클릭합니다.
  3. 검색창에 그리드 또는 Grid를 입력하거나 하단 '그리드' 항목의 [전체 보기]를 클릭합니다.
  4. 3~4개의 공간으로 나뉜 분할 그리드(예: 상단 대형 1개 + 하단 소형 2개)를 선택하여 작업 공간에 넣습니다.
핵심 팁: 그리드는 캔버스 전체에 자동으로 꽉 차며, 각 영역의 크기는 경계선을 드래그하여 자유롭게 조절할 수 있습니다.
STEP 2

프레임(Frame)과 요소 사진 채우기

  1. 프레임 검색 및 작업창 추가 방법:
    1. 좌측 메뉴바에서 [요소 (Elements)] 탭을 클릭합니다.
    2. 검색창 아래로 스크롤하여 '프레임 (Frames)' 카테고리를 찾거나, 검색창에 프레임 또는 Frame (예: 원형 프레임, 찢어진 종이, 아치, 알파벳)을 검색한 후 [모두 보기]를 클릭합니다.
    3. 목록에서 초원/구름 배경이 들어간 원하는 형태의 프레임을 클릭하거나 작업 캔버스 중앙으로 드래그하여 배치합니다.
  2. 좌측 [사진] 탭 또는 [업로드] 메뉴에서 원하는 고화질 사진을 선택합니다.
  3. 사진을 드래그하여 그리드 각 칸과 중앙 프레임 위로 끌고 가면 사진이 프레임 내부로 쏙 들어갑니다.
  4. 프레임 안 들어간 사진을 더블 클릭하여 사진의 위치(구도)와 크기를 미세 조절합니다.
STEP 3

텍스트 추가 및 4가지 입체 글씨 효과 적용하기

  1. 좌측 [텍스트] 메뉴에서 [제목 추가]를 클릭하여 메인 타이틀 문구를 입력합니다 (예: MODERN ART GALLERY).
  2. 상단 폰트 선택창에서 가독성이 뛰어난 두꺼운 산세리프 폰트(예: Pretendard ExtraBold, Black Han Sans, Montserrat)를 선택합니다.
  3. 텍스트를 선택한 상태에서 상단 도구 모음의 [효과 (Effects)] 버튼을 클릭합니다.
  4. 상황에 따른 글씨 효과 레시피를 적용합니다:
    네온 (Neon)

    야경, 클럽, 화려한 강조 문구에 적합. 강도 50~80 설정 후 밝은 형광색 지정.

    스플라이스 (Splice)

    세련된 아웃라인+그림자 효과. 두께 50, 오프셋 40, 주황/파랑 대비 색상 설정.

    곡선 (Curve)

    하단 [형형 (Shape)] 옵션에서 곡선 선택. 둥근 프레임이나 아치 주변을 감싸도록 곡률 조절.

    그림자 (Shadow)

    사진 배경 위에 글자를 명확히 돋보이게 하기 위해 오프셋 50, 흐림 30, 투명도 40 지정.

실습 체크리스트 & 저장하기

학습 목표

시선을 한눈에 사로잡는 POP(Point of Purchase) 글씨체와 톡톡 튀는 테두리/입체 효과, 손글씨 느낌의 스티커 요소를 조합하여 매장 할인 이벤트, 카페 신메뉴, 팝업스토어 홍보 포스터를 제작합니다.

STEP 1

POP 느낌의 두껍고 귀여운 폰트 선정 및 텍스트 구성

  1. 캔버스 크기: A4 세로 (210 x 297 mm) 또는 인스타그램 포스터로 시작합니다.
  2. 배경색을 눈에 잘 띄는 상큼한 노란색(예: #FFD500) 또는 비비드 오렌지(#FF5E00)로 변경합니다.
  3. 핵심 이벤트 문구를 크게 입력합니다 (예: 파격세일 50%, 신메뉴 출시!, 오늘만 이가격).
  4. 캔바 폰트 목록에서 POP 스타일에 어울리는 두껍고 친근한 폰트를 검색하여 변경합니다:
    여기어때 잘난체 티몬 소리체 배달의민족 도현체 Sandoll 호빵체 Gmarket Sans Bold
STEP 2

POP 핵심! 2중 외곽선(테두리) & 입체 테두리 효과 만들기

  1. 1차 윤곽선 적용: 텍스트 클릭 ➔ [효과] ➔ [윤곽선 (Outline)] 선택. 테두리 두께를 70~100으로 두껍게 주고, 색상을 '흰색(#FFFFFF)'으로 설정합니다.
  2. 2차 검은색 외곽선(복제 기법):
    • 완성된 1차 텍스트를 선택하고 Ctrl + D (복제) 합니다.
    • 복제된 텍스트의 효과를 [윤곽선] ➔ 두께 100, 색상을 '검은색(#000000)'으로 지정합니다.
    • 검은색 텍스트를 맨 뒤로 보내기(Ctrl + [)한 후, 흰색 텍스트 바로 뒤에 겹치면 완성도 높은 POP 2중 테두리가 완성됩니다!
  3. 스플라이스(Splice)를 활용한 쉬운 입체 POP:
    • 텍스트 클릭 ➔ [효과] ➔ [스플라이스] 선택.
    • 두께 50 / 오프셋 50 / 방향 -45도 / 내부색상은 노랑, 테두리색은 검은색으로 설정.
STEP 3

POP 분위기를 극대화하는 요소 스티커 및 리본 배치

  1. [요소] 탭 검색창에 다음 키워드를 검색합니다:
    폭발 스티커, 말풍선, 할인 배너, POP 리본, 손글씨 화살표, 반짝이 그래픽
  2. 가격 강조 박스(예: 9,900원) 뒤에 빨간색 강렬한 폭발 모양 스티커 요소를 배치합니다.
  3. 글자 각도를 약간 비스듬하게(5~10도 회전) 기울여 생동감 있고 역동적인 느낌을 연출합니다.

실습 체크리스트

학습 목표

키워드를 활용하여 프롬프트로 고품질 디지털 아트(Digital Art)를 생성하고, 이를 실제 제품에 적용된 것처럼 보여주는 목업(Mockup) 합성 노하우 3가지 방법을 익깁니다.

STEP 1

키워드로 디지털 아트 그래픽 생성/수집

  1. 캔바 왼쪽 앱 메뉴 ➔ [Magic Media (매직 미디어)] 또는 [요소] 검색을 엽니다.
  2. 디지털 아트 생성을 위해 아래 키워드 예시를 프롬프트창에 복사하여 입력합니다:
    Cyberpunk neon city sunset, 3D synthwave aesthetic, isometric digital illustration, highly detailed, vibrant cyan and magenta gradient --ar 1:1
  3. 생성된 아트워크 중 가장 마음에 드는 이미지를 캔버스에 추가하고 PNG 파일로 저장합니다.
STEP 2

디지털 아트를 목업에 넣는 3가지 방법

방법 1
Canva 스마트목업 (Smartmockups) 자동 합성
  1. 디지털 아트 이미지를 클릭하고 상단 [사진 편집 (Edit Photo)]을 클릭합니다.
  2. 효과 탭에서 [Smartmockups] 메뉴를 선택합니다.
  3. 스마트폰, 노트북, 티셔츠, 액자, 머그컵 중 원하는 제품 선택.
  4. 클릭 한 번으로 이미지가 제품에 입혀지는 자동 합성 완료!
방법 2
목업 전용 프레임(Frame) 활용 합성
  1. [요소] 탭에서 컴퓨터 프레임, 아이패드 프레임, 액자 프레임을 검색하여 배치합니다.
  2. 내 디지털 아트 이미지를 해당 디바이스 화면 프레임 안으로 드래그하여 집어넣습니다.
  3. 투명도나 약간의 그림자 요소를 추가하여 이질감을 줄여줍니다.
방법 3
누끼(배경제거) PNG + 블렌딩 직접 합성
  1. [요소]에서 빈 액자나 액티비티 목업 이미지(배경이 포함된 실제 사진)를 불러옵니다.
  2. 내 디지털 아트의 투명도(Opacity)를 85~90%로 살짝 낮추거나 [위치] ➔ 레이어 조절로 액자 프레임 안쪽에 정밀 배치합니다.
  3. 상단에 '유리 반사 광원 (Glass Reflection)' 요소를 얹어 현실감을 200% 극대화합니다.
CHECKLIST

실습 체크리스트

학습 목표

포토샵 고급 테크닉이었던 '바닥 바반사 미러링(Mirror Reflection) 효과'와 '그라데이션 그림자'를 캔바에서 그대로 구현하여 프리미엄 화장품/전자제품/수제화 상세페이지 메인 이미지를 고급스럽게 연출합니다.

STEP 1

제품 이미지 준비 및 누끼(배경 제거) 처리

  1. 상세페이지용 세로 캔버스 860 x 1200 px (스마트스토어/쿠팡 표준)를 만듭니다.
  2. 고급스러운 어두운 배경(대리석 패턴 또는 신비로운 오페라 퍼플/매트 블랙)을 설치합니다.
  3. 메인 제품 사진(예: 향수병, 무선 이어폰, 스킨케어 병)을 불러옵니다.
  4. 이미지 선택 ➔ [사진 편집] ➔ [BG Remover (배경 제거사)] 클릭하여 제품만 선명하게 따냅니다.
STEP 2

포토샵 스타일 미러링 (거울 반사) 효과 3단계 완성법

1
제품 이미지 복제 및 상하 뒤집기

누끼 딴 제품 이미지를 선택하고 Ctrl + D로 복제한 후, 상단 [뒤집기 (Flip)] ➔ [세로로 뒤집기 (Flip Vertical)]를 실행합니다.

2
위치 맞추기 및 레이어 순서 지정

뒤집힌 복제 제품을 원본 제품의 바로 아래 바닥면 접점에 꼭 맞게 밀착시킵니다. 그 후 뒤집힌 이미지를 Ctrl + [로 원본 뒤로 보냅니다.

3
투명도 조절 & 그래디언트 마스크(Gradient Mask) 처리

뒤집힌 반사 이미지의 투명도(Transparency)를 35% ~ 45%로 낮춥니다. 더 자연스럽게 만으려면 [요소]에서 투명 그라데이션 (Gradient Blur) 요소를 가져와 반사 이미지 하단에 덮어주면 아래로 갈수록 아득히 사라지는 완벽한 미러링이 완성됩니다!

STEP 3

바닥 입체 접점 그림자(Drop Shadow) 추가

  1. [요소] 탭에서 Oval Shadow 또는 Drop Shadow 또는 타원 그림자를 검색합니다.
  2. 검은색 아른거리는 타원 그림자를 제품 밑 바닥 접촉면에 넓게 깔아주어 제품이 공중에 떠 있지 않고 묵직하게 안착된 효과를 줍니다.
  3. 고급스러운 로고 텍스트와 PREMIUM EDITION 문구를 반사면 주변에 배치합니다.
CHECKLIST

실습 체크리스트

학습 목표

페이지 복제 기능과 0.1~0.3초 단위의 미세 타이밍 조절을 통해, 별도의 복잡한 영상 편집 툴 없이 캔바만으로 인스타그램 릴스/숏폼용 톡톡 튀는 스탑모션(Stop-Motion) 애니메이션 영상을 제작합니다.

STEP 1

스탑모션 컨셉 설정 및 1번 프레임 디자인

  1. 캔버스 크기: 모바일 동영상 (1080 x 1920 px)을 선택합니다.
  2. 스탑모션 주제를 선정합니다 (예: 커피 잔에 커피가 조금씩 차오르는 효과, 글자가 한 글자씩 살아 움직이는 효과, 캐릭터가 껑충껑충 뛰는 효과, 상자 뚜껑이 열리며 상품이 튀어나오는 효과).
  3. 1번 페이지에 시작 요소(예: 닫힌 선물 상자 스티커)를 배치하고 위치를 잡습니다.
STEP 2

페이지 연속 복제(Duplicate) & 미세 변형(Move/Rotate)

  1. 하단 타임라인/페이지 그리드 보기에서 1번 페이지 상단의 [페이지 복제 (Duplicate)] 아이콘(또는 Ctrl + D)을 누릅니다.
  2. 복제된 2번 페이지의 요소를 아주 조금 이동시키거나 회전(3~5도), 또는 크기를 약간 확대/축소합니다.
  3. 다시 2번 페이지를 복제하여 3번 페이지를 만들고, 똑같이 미세하게 이동시킵니다.
  4. 이 과정을 10~15개 페이지 이상 반복하여 프레임 바이 프레임(Frame-by-frame) 움직임을 완성합니다.
    팁: 변화의 폭이 작을수록 애니메이션이 부드러워지고, 변화가 불규칙하면 스탑모션 특유의 재밌고 귀여운 툭툭 끊기는 감성이 살아납니다.
STEP 3

페이지 재생 시간(Timing) 0.1~0.3초 괄호 설정 & MP4 / GIF 다운로드

  1. 상단 도구 모음의 시계 모양 아이콘 [시간 (Timing)]을 클릭합니다.
  2. 시간 슬라이더를 조절하여 0.2초 (속도감을 원하면 0.1초)로 변경합니다.
  3. 하단의 [모든 페이지에 적용 (Apply to all pages)] 버튼을 반드시 클릭하여 전체 페이지 속도를 통일합니다.
  4. 우측 상단 [재생(Play)] 버튼을 눌러 스탑모션 영상을 미리보기 테스트합니다.
  5. [공유] ➔ [다운로드] ➔ 파일 유형을 MP4 동영상 또는 숏폼/웹용 GIF로 지정하여 내보냅니다.
CHECKLIST

실습 체크리스트

학습 목표

크몽, 에이블리, 굿노트(Goodnotes) 마켓, 엣시(Etsy) 등에서 실제 수익화가 가능한 디지털 워크시트지(플래너/가계부/스터디 플래너)를 제작하고, 클릭하면 해당 페이지로 바로 이동하는 클릭가능한 하이퍼링크(Hyperlink) PDF를 완성합니다.

STEP 1

디지털 워크시트 규격 설정 및 표(Table) 서식 작성

  1. 캔버스 크기: A4 세로 (210 x 297 mm) 또는 태블릿 전용 US Letter / iPad Screen Size.
  2. [요소] 탭에서 '표 (Table)'를 검색하여 추가합니다.
  3. 행과 열을 추가/삭제하여 워크시트 레이아웃(예: 날짜 | 시간 | 할 일 | 완료 여부 | 메모)을 구성합니다.
  4. 표 테두리 색상, 두께, 셀 배경색(파스텔 톤 권장)을 브랜드 스타일에 맞춰 깔끔하게 정돈합니다.
STEP 2

다중 페이지 구성 & 탭 목업 네비게이션 만들기

  1. 페이지를 추가하여 총 5페이지를 만듭니다 (1p: 표지, 2p: 연간 플래너, 3p: 월간 플래너, 4p: 주간 플래너, 5p: 모눈 노트).
  2. 우측 사이드에 다이어리 색인 탭 느낌의 [사각형 도형] 4개를 세로로 배치합니다 (탭 이름: YEAR, MONTH, WEEK, NOTE).
  3. 이 탭 디자인을 모든 페이지의 동일한 위치에 복사/붙여넣기(Ctrl + C ➔ Ctrl + V)합니다.
STEP 3

핵심! 인터랙티브 하이퍼링크(Link) 연결 & PDF 다운로드

  1. 1페이지의 MONTH 탭 버튼 요소를 선택하고 마우스 우클릭 ➔ [링크 (Link)] (단축키 Ctrl + K)를 클릭합니다.
  2. 링크 입력창에 외부 URL 대신 하단 '디자인의 페이지' 목록 중 3페이지 (월간 플래너)를 선택 연결합니다.
  3. 동일한 방식으로 모든 탭에 해당 페이지 번호를 매핑 링크 걸어줍니다.
  4. 상업적 다운로드 설정:
    • 우측 상단 [공유] ➔ [다운로드] 클릭.
    • 파일 유형: PDF 인쇄 (PDF Print) 또는 PDF 표준 (PDF Standard) (디지털 기기 사용용은 Standard 추천).
    • 태블릿 굿노트/노타빌리티 앱에서 열었을 때 탭을 터치하면 해당 위치로 즉시 이동합니다!

Magic Media - 텍스트로 고화질 일러스트/사진 생성

원하는 장면을 글로 묘사하면 캔바 AI가 몇 초 만에 4장의 고화질 이미지로 그려냅니다.

AI TOOL 2

Magic Edit (매직 편집) - 부분 수정 및 오브젝트 교체

이미지의 특정 부분만 브러시로 문지르고 프롬프트를 입력해 새로운 물체로 감쪽같이 합성 변경합니다.

  1. 사진 클릭 ➔ [사진 편집] ➔ [Magic Edit] 클릭.
  2. 인물이 들고 있는 '커피 잔' 부분을 브러시로 칠합니다.
  3. 요청창에 화려한 장미 꽃다발 입력 후 [생성] 클릭 ➔ 커피 잔이 꽃다발로 자연스럽게 변환!

AI TOOL 3

Magic Eraser (매직 지우개) - 불필요한 요소 흔적 없이 지우기

배경에 있는 전선, 지나가는 사람, 지저분한 흠집을 브러시질 한 번으로 주변 복원하며 지웁니다.

  1. [사진 편집] ➔ [Magic Eraser] 선택.
  2. 지우고 싶은 불필요한 배경 요소를 쓱쓱 문지르면 주변 배경 픽셀을 AI가 자동 합성하며 완벽 제거.
